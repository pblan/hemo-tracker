# Install on macOS

1. Download the unsigned macOS disk image from the project release.
2. Open the `.dmg` file.
3. Move **Hemo Tracker.app** to **Applications**.
4. Open **Hemo Tracker.app**.
5. Read the unsigned publisher warning.
6. Continue only when you trust the release source and checksum.

Do not disable global macOS security protections. If the application is not from a trusted release source, cancel the installation.

The first start creates a local encrypted vault. Keep the passphrase and recovery key separate.
