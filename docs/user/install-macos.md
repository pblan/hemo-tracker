# Install on macOS

1. Download the unsigned macOS application from the project release.
2. Open the archive and move **Hemo Tracker.app** to **Applications**.
3. Open **Hemo Tracker.app**.
4. Read the unsigned publisher warning.
5. Continue only when you trust the release source and checksum.

Do not disable global macOS security protections. If the application is not from a trusted release source, cancel the installation.

The first start creates a local encrypted vault. Keep the passphrase and recovery key separate.
