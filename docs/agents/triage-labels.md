# Triage labels

The engineering skills use five triage roles.

| Role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The issue needs more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the issue. |
| `ready-for-human` | `ready-for-human` | A human must implement the issue. |
| `wontfix` | `wontfix` | The team will not implement the issue. |

Use the tracker label that maps to the required role.
